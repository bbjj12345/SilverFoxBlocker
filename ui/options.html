命中风险后，禁用页面全部下载与重定向链接（推荐保持开启）

ICP 备案权威核验
向公开备案查询接口核实域名备案真伪：确有备案则不再误判仿冒，页面写了备案号但查无记录则判定为盗用他人备案。仅在核验有价值时才发起（页面展示备案号、.cn 站查不到备案标识、或已判仿冒），且只发送域名、不发送任何浏览内容。关闭后仅做页面文字扫描

中招后急救步骤：

  1. 修改 hosts 文件。hosts 文件位于 C:\Windows\System32\drivers\etc，一般有 hosts（文件类型为"文件"）和 hosts.ics（文件类型为"ICS 文件"）。文件类型为"文件"的 hosts 才是需要修改的。将 hosts 文件复制到桌面，用记事本打开，可能会看到类似 127.0.0.1 weishi.360.cn 的内容，可以删掉这些内容，或者用 # 注释掉它们。把修改后的 hosts 文件覆盖回 C:\Windows\System32\drivers\etc 即可。
  2. 关闭内存完整性。在"设置 → 隐私和安全性 → Windows 安全中心 → 设备安全性 → 内核隔离"关闭"内存完整性"，重启后生效。
  3. 使用火绒恶性木马专杀工具无签名版。让专杀工具清除所有检测到的威胁，完成后重启。如果可以正常安装杀毒软件，则认为银狐木马被清除；记得用杀毒软件进行全盘扫描，确认银狐木马已被清除干净。
  4. 若杀毒软件安装失败、无法正常打开，或专杀工具被阻止运行，且判断为"被银狐木马阻止"，则下载 360 系统急救箱独立版。解压后运行 360急救箱运行不了请点我-加强版.bat，勾选"强力模式"进行全盘扫描。让急救箱清除所有检测到的威胁，完成后重启。清除完成后，再尝试安装杀毒软件。若成功安装，则更新病毒库，进行全盘扫描。
  5. 重新开启内存完整性，做好后续防护。在日常生活中，请优先信任杀毒软件的判断。
  6. 如果需要更多工具，请访问以下链接：
